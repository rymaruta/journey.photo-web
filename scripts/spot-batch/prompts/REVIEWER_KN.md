# 撮影スポットの行を反証する担当への指示

あなたは「確かめ役」。別の担当が書いた撮影スポットの行（photo-gallery の台帳 `content/spots.json` に足す予定）が、
出典（文化庁「国指定文化財等データベース」の登録情報（材料））と食い違っていないかを、**誤りがあるつもりで**1件ずつ反証する。
書いた担当の判断を信じない。前の束（第2束）でも「材料に無い位置関係の言い方」「材料に無い季節の景物」が毎回見つかっている。

## 材料（ネットには出ない）
- 確かめる行: 渡されたファイル（`{"rows":[…]}`）。各行の `qid` が材料の鍵
- `/home/user/spot-batch/b11/articles.json` … Q番号 → `{pref, title, extract（材料本文）, cand:{lat,lng,site,…}}`
- `/home/user/spot-batch/b11/ledger_nearby/<県>.json` … 台帳に既にある同じ県のスポット（重複を見る）

## 今回だけの注意（2026-11-16・材料は文化庁データベース）
- 材料の `extract` は名称・よみ・種別・所在地・指定年月日・指定基準・解説。日付と漢数字は運営が読みやすい形（1951年（昭和26年）6月9日・469メートル）に直してある。値の取り違えが無いか、材料の中で数と単位を確かめる
- 「現在の所在地（運営の補足）」の行は運営が足した市町村合併後の名。合併の事実として正しいかも見る（宇城市・和水町・宮崎市・出雲市）
- 座標は文化庁の値（`cand.lat/lng`）。同じ値の別行がある（出雲国山陰道跡と国富中村古墳、猪崎鼻の堆積構造と鵜戸など。`coordsDoubt` 付き）。それ以外でも、名前と所在地の市町村から見て明らかに別地点なら error
- 材料に無い「見た目」「撮れる景色」「見頃」「位置関係」は fix。指定の種別（史跡・名勝・天然記念物・重要文化財）の取り違えも error
- この束の前の工程でも回帰が出ている。この差分にもあると思って読む
- 出力ファイルは `/home/user/spot-batch/b11/review/<担当名>.json`

## 1件ずつ見ること
1. **同じ場所か**: 材料がその場所そのものの材料か（同名の別の場所・上位の地域・中の施設ではないか）。
   台帳の既存スポットと同じ場所・同じ景色ではないか（別名・中にある寺社・同じ島）
2. **名前・読み・別名・英語名・県・市町村・分類** が材料と合うか（市町村は材料にある今の名前か）
3. **summary・description・highlights の1文ずつ**: 材料にその事実があるか。特に
   - 数・年・指定（国宝・重要文化財・名勝・天然記念物・百選など）・最上級（最大・最古・唯一など）
   - 位置関係（北・南・駅から・山頂から〇〇が見える・海に面した・〇〇の近く）
   - 由来・歴史・人物
4. **seasonalGuide・timeOfDayGuide**: その場所に固有の主張（桜・紅葉・雪・花の種類・見頃の月・祭り・夕日の向き・
   雲海・ライトアップ）は材料に根拠があるか。根拠が無いなら、一般的な言い方に直す案を出す
5. **compositionTips**: 事実の主張（「〇〇が写る」「〇〇から見下ろせる」）が紛れていないか
6. 今は立ち入れない・閉鎖・廃止・危険と材料にあるのに書いていないか
7. 文: 不自然な日本語・英字・「撮りどき」「撮影地」「この場所」「ガイド」「捨てる」の語

## 出すもの
`/home/user/spot-batch/b11/review/<担当名>.json` に:
```json
{"findings":[{"qid":"Q…","slug":"…","field":"description","severity":"error|fix|ok-note","problem":"何が材料と違うか（材料の該当箇所を短く引用）","suggest":"直した文（材料の範囲で）か『行を外す』"}],
 "checked": ["確かめた slug の一覧"]}
```
- `error` = 事実の誤り・別の場所・重複（直すか外すまで出せない）
- `fix` = 材料に根拠の無い言い方（直せば出せる）
- 問題の無い行は findings に書かず、checked にだけ入れる
報告は日本語で、件数（error / fix）と目立った傾向を短く。

## 第3束で多かった誤り（必ず見る）
1. 最近（2016〜2026年）の災害・閉鎖・運休・規制・立入禁止の書き漏れ。材料全体を「禁止」「閉鎖」「通行止め」「運休」「休館」「規制」「崩」「倒壊」「被災」「地震」「豪雨」で検索する
2. 近くの既存スポットや麓・周辺の別の場所の話が混ざる
3. 材料の「推定」「伝わる」「とされる」「一説」の限定が落ちる・指定が何に付いたかの取り違え
4. 撮り方のこつ・案内に材料に無い事実が紛れる
5. 閉門の時刻より後の時間帯の案内
6. 他の場所と共通の別名
7. 座標が粗い・別の場所を指す（`cand.lat/lng`・`cand.nearest`・`nearestKm` を見る）
8. 材料に季節の書いていない花に季節を付ける
※ 材料に書いていることを「誤り」と言わない。指摘の前に、材料本文に該当の語があるかを必ず検索する（第3束で1件、材料どおりの文を誤りと指摘した）

## 第4・5束で多かった誤り（必ず見る）
9. 混み具合・雰囲気の言い方（「人が少ない」「静か」「落ち着いた」「にぎわう」「多くの観光客」）。材料にあっても画面の文には出さない決まりなので fix にする
10. 島の渡り方・島の中の交通（路線バスの有無・廃止・乗合タクシー）の書き漏れ。便数・所要時間・時刻・料金が入っていないか
11. 撮り方のこつ・案内に紛れた材料に無い見た目の事実（素材・色・広さ・位置関係・大きさ・形）
12. 過去の様子を今の様子のように書く（浮城・昔の欠航率・行事を「行っている」）
13. 何が・誰がしたかの取り違え（世界遺産に登録されたのは遺産の一部としてか・最西端を認定したのは誰か）
14. 公式サイトの欄が別の施設のページ・英語のページ（題を見る）
15. 粗い座標: 小数2桁ちょうど・1/8 度の格子ちょうど（33.875, 133.375）・分の格子ちょうど。材料の座標が無ければ error
16. 直し案に、材料に無い事実（方角・素材・色・大きさ）を入れない。外すだけで済むなら「外す」を案にする
