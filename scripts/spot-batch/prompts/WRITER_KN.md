# 撮影スポットの行を書く担当への指示

journey.photo の撮影スポット台帳（photo-gallery の `content/spots.json`）に、新しい国内のスポットを足す。
あなたは「書く担当」。**ネットには出ない**。材料は渡したファイル（日本語版 文化庁データベース の本文・Wikidata の事実）だけ。

## 材料
- `{{DIR}}/articles_<組>.json`（渡された組の分） … キー `KN<種別>-<番号>` → `{pref, title, extract, source, cand:{lat,lng,types}}`
  - **今回は 文化庁データベース ではなく、文化庁「国指定文化財等データベース」の登録情報が材料**（2026-11-16・owner「自治体・観光協会・文化庁の文化財データベース 足して」）。
    `extract` は 名称・よみ・種別・所在地・指定年月日・指定基準・解説（文化庁の解説文）。`source` がその頁の URL
  - 座標 `cand.lat/lng` は文化庁の値（正確）。`qid` と書いてある所には、この `KN…` のキーをそのまま書く
- `{{DIR}}/ledger_nearby/<県>.json` … その県で台帳に既にある全スポットの名前・別名・座標（重複を避けるため）
- 手本: 台帳の既存の行（`{{PG}}/content/spots.json` の `aiCheck.checkedAt` が "2026-10-31" の行）。ただし文体と形だけ見る。**材料の事実が少ないので、書く量は材料に合わせて短くてよい**

## 選び方（担当分のキーのうち、観光で訪ねられるものは書く）
- 件数の上限は無い。数合わせの見送りはしない。見送るときは `skipped` の `reason` に具体的な理由
- 書く: 史跡（城跡・古墳・遺跡・寺社跡・町並み）・名勝（庭園・景勝地）・天然記念物（巨樹・渓谷・洞窟・植物群落・地質）・
  重要文化財の建造物（神社・寺・民家・橋・近代建築）・伝統的建造物群・文化的景観
- 見送る: 立ち入れない・一般に見られないと材料にある物（個人邸で非公開などは材料に無いので判断しない＝書いてよい）、
  複数の遠く離れた地点をまとめた登録（例「おくのほそ道の風景地」）、材料が名称と所在地だけで、書ける事実が「国指定の○○である」以外に何も無い物は、
  summary 40字・description 60字を**事実の水増し無しで**満たせなければ見送る
- 台帳に既にある場所と同じ（別名・中にある施設）は書かない。`ledger_nearby` と見比べる

## 書く形（1件 = 1つの JSON オブジェクト）
```json
{
  "qid": "KN401-1234（キーそのまま）",
  "slug": "ascii-lowercase-hyphen（英語名ベース。台帳の slug と重ならない。県名などで区別してよい）",
  "name": "材料の題（括弧の曖昧さ回避は外す）",
  "nameEn": "英語名（材料・Wikidata にある英語表記か、素直なローマ字＋種類。例 Fukuroda Falls）",
  "reading": "ひらがなの読み（材料の冒頭にある読み）",
  "aliases": ["材料にある別名・旧称（無ければ []）"],
  "address": "県＋市町村（材料にある範囲。番地は書かない）",
  "region": {"country": "日本", "prefecture": "○○県", "city": "市町村（郡があれば郡から。例 島尻郡渡嘉敷村）"},
  "category": "既存の分類から: 寺社 / 城 / 城跡 / 滝 / 湖沼 / 渓谷 / 海岸 / 岬 / 島 / 山岳 / 公園 / 庭園 / 橋 / 町並み / 棚田 / 灯台 / 温泉 / 高原 / 湿原 / 鍾乳洞 / 展望台 / 史跡 / 建築 / 産業遺産 / 樹木 / 植物園",
  "summary": "1〜2文。どこにある何か（材料にある事実だけ）",
  "description": "60字以上・2〜3文。材料にある事実と、撮れる景色",
  "highlights": ["見どころ 2〜4 個（材料にあるもの）"],
  "seasonalGuide": [{"season": "spring|summer|autumn|winter", "text": "12字以上"}],
  "timeOfDayGuide": [{"time": "dawn|morning|day|goldenHour|dusk|night", "text": "12字以上"}],
  "compositionTips": ["撮り方のこつ 1〜3 個（運営の助言。事実の主張を含めない）"],
  "officialWebsiteUrl": "cand.site が https のときだけ。無ければ書かない",
  "articleTitle": "articles.json の title（名称）"
}
```
- seasonalGuide は**2つ以上**、timeOfDayGuide も**2つ以上**。**夏をできるだけ入れる**（夏の案内が少ない）
- 季節・時間帯の案内は、**材料にある季節の景物**（桜・紅葉・雪・花の名所・祭り・夕日の名所など）を優先する。
  材料に無い場合は、誰にでも当てはまる一般的な光の話（「夕方は斜めの光で陰影が出る」）にとどめ、
  **その場所に固有の事実（花の種類・見頃の月・夕日が見える向き・祭りの日）を材料なしで書かない**

## 🔴 嘘を書かない決まり（いちばん大事）
- 数（高さ・長さ・年・段数・本数・面積）・指定（国宝・重要文化財・名勝・天然記念物・日本の滝百選 など）・
  最上級（日本一・最大・最古・唯一）は、**材料の本文にその語・その数があるものだけ**。数は材料と同じ値で書く
  （丸めない・「約」を勝手に付けない）
- 位置関係（「〇〇の北」「駅から歩いて」「山頂から〇〇が見える」「海に面した」）も**材料にあるものだけ**。
  第2束で「材料に無い位置関係の言い方」が何度も見つかった。迷ったら書かない
- 交通・駐車場・料金・営業時間・所要時間・規制は**書かない**（出典の要る項目で、AI 照合では出せない）
- 文体はです・ます調の簡潔な日本語。英単語・簡体字・Markdown の `**` を混ぜない
- 画面の文に「撮りどき」という語を使わない。「撮影地」「この場所」「ガイド」も使わない（呼び名の決まり）。
  「捨てる」も使わない

## 出すもの
`{{DIR}}/out/<組>.json` に次の形で書く:
```json
{"rows": [ …上の形… ], "skipped": [{"qid": "Q…", "title": "…", "reason": "…"}]}
```
担当分のキーは全部、rows か skipped のどちらかに入れる。
書き終えたら、自分で1件ずつ材料と見比べ、材料に無い事実・位置関係が無いか確かめ直してから終える。
報告は日本語で、書いた件数・見送った件数（理由の内訳）・迷ったところを短く。

## 第3束で分かったこと（必ず守る）
- 同じ キーが2つの県に割り当てられていることがある。材料に書かれた県の方で1回だけ書く。ほかの組で既に書いた キー・名前は書かない
- 本文に英字を入れない（「266.6m」「3km」「JR」「U字」は照合で落ちる）。「メートル」「キロメートル」と書く。材料が「1931年4月1日」の形なら、その形で書く
- 紹介文（summary）は **40字以上**、説明（description）は 60字以上
- 山小屋に泊まるのが前提の山・縦走でしか行けない山は書かない
- **材料の終わりの方の「歴史」の節にある最近（2016〜2026年）の災害・閉鎖・運休・通行止め・立入禁止・休館を必ず検索して読む**（「禁止」「閉鎖」「通行止め」「運休」「休館」「規制」「崩」「倒壊」「被災」「地震」「豪雨」）。書き漏れが一番多かった。観光で行けるかが材料から分からない場所（島の航路が島民限定など）は書かない。規制が材料にあれば description か compositionTips に材料どおり書く（料金・時刻表は書かない）
- 閉門・閉園の時刻が材料にある場所は、その時刻より後の時間帯の案内を書かない
- 近くの既存スポット（`ledger_nearby`）や麓・周辺の別の場所の話を、その場所の見どころとして混ぜない
- 材料の「推定」「伝わる」「とされる」「麓へ」「一説」などの限定を落とさない。指定（名勝・重要文化財など）は、何に付いた指定かを材料どおりに書く。「一宮」は相手の神社も称するなら「一宮を称する」
- 撮り方のこつ・案内に、材料に無い事実（色・並び・中の明るさ・奥にあるもの・「朝は海が静か」）を入れない
- 材料に咲く季節の書いていない花に、季節を付けない
- 別名に、他の場所と共通の呼び名（「〇〇の奥座敷」「つつじ寺」など）を入れない
- 同じ名前が台帳かほかの組にあるときは、地名を前に付けて分ける（例「松山 浄土寺」。括弧の別名で分けると照合が括弧を外して比べるので落ちる）
- Wikidata の座標（`cand.lat/lng`）が小数1〜2桁と粗いとき、台帳の最寄り（`cand.nearest`）が明らかに別の地域のときは、その行に `"coordsDoubt": true` を付ける（座標はこちらで材料の座標と突き合わせて直す）
- 最後に、自分で1件ずつ材料と見比べ直す

## 第4束で分かったこと（必ず守る）
- 「朝は人が少ない」「参拝者が少なく」「静か」「落ち着いて」のような混み具合の言い方は材料に根拠が無いので書かない（第3束・第4束で合わせて約130か所直した）。季節・時間帯の案内は、材料にある景物か、光・空気の一般的な話にする。開園時刻が材料に無い所に「朝の早い時間」と書かない
- 島は、材料にある渡り方（定期船・航空路・車を持ち込めるか・島内のバス・欠航）を description に書く。便数・所要時間・時刻・料金は書かない。島に泊まらないと撮れない時間帯は前提がわかる書き方にするか書かない
- 活火山・登山道の規制・噴火警戒は材料どおりに書く。近づけない所は書かない
- 画面の文に「材料では」「と材料にあります」のような出典の言い方を出さない
- 撮り方のこつ・案内に、材料に無い事実（方角・色・素材・配置・見える物）を入れない

## 第5束で分かったこと（必ず守る）
- 撮り方のこつ・季節・時間帯の文に、材料に無い**見た目の事実**（素材・色・広さ・位置関係・大きさ・形・「まっすぐ延びる」「尖った」「裾野」「起伏」「堀に水がある」）を入れない。直しのときに言い換えで入りやすい（確かめ役の直し 68 件のうち、この型がいちばん多かった）。一般的な光の話（「斜めの光で陰影が出る」「穏やかな明るさで写せる」）にとどめる
- **昔の様子を今のことのように書かない**（浮城と呼ばれた・欠航率・行事を行ってきた・丸馬出や三日月堀があった）。材料が過去形・年つきなら「かつては」「最盛期には」「〇〇年から」と限る
- 島は渡り方に加えて**島の中の交通**（路線バスが無い・廃止された・予約制の乗合タクシーだけ・送迎は利用者向け）も材料どおりに書く
- 「落ち着いた」「にぎわう」「多くの観光客が訪れる」も書かない（材料にあっても、画面の文には混み具合を出さない）
- 道路の崩落・通行止めの文を外すと、材料にある災害そのものまで消えることがある。災害は「〇〇年に〜で通行止めになり、〜が難しくなりました（〇〇年に〜は通れるようになっています）」の形で、今の状況を言い切らずに残す。山頂直下の鎖場・急坂・沢の渡渉など、材料にある登山道の危険も書く
- 山: 山小屋に泊まらないと行けない・日帰りで行けるかが材料から分からない山は見送る（燕岳・空木岳・南駒ヶ岳を外した）
- 名前の付け方: 台帳の既存の行が「戸隠神社 奥社の杉並木」なら、同じ寺社の別の場所は「戸隠神社 中社・宝光社」の形にそろえる（照合が名前の最後の語と材料の題を比べるので、合わないときは書いた担当が `subject_ok.json` に slug を足すよう報告する）
- 照合は「2015年9月17日」のように年のすぐ後に数字が続く書き方だと年を拾わない。材料と同じ日付の形で書く
- 「若冲」のように日本語で正しい字が簡体字の見張りに掛かることがある。字を変えずに報告する

## 時期で変わる情報には「※最新の情報は〇〇でご確認ください。」を付ける（2026-11-13 owner）

閉鎖・休止・運休・規制・立入禁止・工事・再整備・予約・拝観・開洞・開門・料金・開館時間・「〇年現在」など、**いまの状態で変わる情報**を
説明・見どころ・季節・時間帯・こつのどこかに書いた行は、**説明（description）の末尾**に次の1文を付ける。judge が付いていない行を落とす。
- `※最新の情報は公式サイトでご確認ください。`（`officialWebsiteUrl` を付ける行）
- `※最新の情報は自治体や観光協会の案内でご確認ください。`（公式サイトの欄が無い行）
- 案内先を指すだけで、事実は足さない。「訪れる前に公式サイトで確認してください」の言い方は使わず、この1文に統一する
- 既に出ている行へは `s21_add_latest_note.py` で機械で付ける（何度流しても同じ）
