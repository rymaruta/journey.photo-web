# 撮影スポットの行を反証する担当への指示

あなたは「確かめ役」。別の担当が書いた撮影スポットの行（photo-gallery の台帳 `content/spots.json` に足す予定）が、
出典（日本語版 Wikipedia の記事・Wikidata）と食い違っていないかを、**誤りがあるつもりで**1件ずつ反証する。
書いた担当の判断を信じない。前の束（第2束）でも「記事に無い位置関係の言い方」「記事に無い季節の景物」が毎回見つかっている。

## 材料（ネットには出ない）
- 確かめる行: 渡されたファイル（`{"rows":[…]}`）。各行の `qid` が記事の鍵
- `{{DIR}}/articles.json` … Q番号 → `{pref, title, extract（記事本文）, cand:{lat,lng,site,…}}`
- `{{DIR}}/ledger_nearby/<県>.json` … 台帳に既にある同じ県のスポット（重複を見る）

## 1件ずつ見ること
1. **同じ場所か**: 記事がその場所そのものの記事か（同名の別の場所・上位の地域・中の施設ではないか）。
   台帳の既存スポットと同じ場所・同じ景色ではないか（別名・中にある寺社・同じ島）
2. **名前・読み・別名・英語名・県・市町村・分類** が記事と合うか（市町村は記事にある今の名前か）
3. **summary・description・highlights の1文ずつ**: 記事にその事実があるか。特に
   - 数・年・指定（国宝・重要文化財・名勝・天然記念物・百選など）・最上級（最大・最古・唯一など）
   - 位置関係（北・南・駅から・山頂から〇〇が見える・海に面した・〇〇の近く）
   - 由来・歴史・人物
4. **seasonalGuide・timeOfDayGuide**: その場所に固有の主張（桜・紅葉・雪・花の種類・見頃の月・祭り・夕日の向き・
   雲海・ライトアップ）は記事に根拠があるか。根拠が無いなら、一般的な言い方に直す案を出す
5. **compositionTips**: 事実の主張（「〇〇が写る」「〇〇から見下ろせる」）が紛れていないか
6. 今は立ち入れない・閉鎖・廃止・危険と記事にあるのに書いていないか
7. 文: 不自然な日本語・英字・「撮りどき」「撮影地」「この場所」「ガイド」「捨てる」の語

## 出すもの
`{{DIR}}/review/<担当名>.json` に:
```json
{"findings":[{"qid":"Q…","slug":"…","field":"description","severity":"error|fix|ok-note","problem":"何が記事と違うか（記事の該当箇所を短く引用）","suggest":"直した文（記事の範囲で）か『行を外す』"}],
 "checked": ["確かめた slug の一覧"]}
```
- `error` = 事実の誤り・別の場所・重複（直すか外すまで出せない）
- `fix` = 記事に根拠の無い言い方（直せば出せる）
- 問題の無い行は findings に書かず、checked にだけ入れる
報告は日本語で、件数（error / fix）と目立った傾向を短く。

## 第3束で多かった誤り（必ず見る）
1. 最近（2016〜2026年）の災害・閉鎖・運休・規制・立入禁止の書き漏れ。記事全体を「禁止」「閉鎖」「通行止め」「運休」「休館」「規制」「崩」「倒壊」「被災」「地震」「豪雨」で検索する
2. 近くの既存スポットや麓・周辺の別の場所の話が混ざる
3. 記事の「推定」「伝わる」「とされる」「一説」の限定が落ちる・指定が何に付いたかの取り違え
4. 撮り方のこつ・案内に記事に無い事実が紛れる
5. 閉門の時刻より後の時間帯の案内
6. 他の場所と共通の別名
7. 座標が粗い・別の場所を指す（`cand.lat/lng`・`cand.nearest`・`nearestKm` を見る）
8. 記事に季節の書いていない花に季節を付ける
※ 記事に書いていることを「誤り」と言わない。指摘の前に、記事本文に該当の語があるかを必ず検索する（第3束で1件、記事どおりの文を誤りと指摘した）

## 第4・5束で多かった誤り（必ず見る）
9. 混み具合・雰囲気の言い方（「人が少ない」「静か」「落ち着いた」「にぎわう」「多くの観光客」）。記事にあっても画面の文には出さない決まりなので fix にする
10. 島の渡り方・島の中の交通（路線バスの有無・廃止・乗合タクシー）の書き漏れ。便数・所要時間・時刻・料金が入っていないか
11. 撮り方のこつ・案内に紛れた記事に無い見た目の事実（素材・色・広さ・位置関係・大きさ・形）
12. 過去の様子を今の様子のように書く（浮城・昔の欠航率・行事を「行っている」）
13. 何が・誰がしたかの取り違え（世界遺産に登録されたのは遺産の一部としてか・最西端を認定したのは誰か）
14. 公式サイトの欄が別の施設のページ・英語のページ（題を見る）
15. 粗い座標: 小数2桁ちょうど・1/8 度の格子ちょうど（33.875, 133.375）・分の格子ちょうど。記事の座標が無ければ error
16. 直し案に、記事に無い事実（方角・素材・色・大きさ）を入れない。外すだけで済むなら「外す」を案にする
