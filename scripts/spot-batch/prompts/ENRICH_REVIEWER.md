# 濃くする束の確かめ役への指示

書く担当が、公開済みの観光スポットの説明を、複数の出典から組み直して書いた。**誤りがあるつもりで**、1文ずつ材料と照らす（抜き取りにしない）。返答・報告はすべて日本語。**ネットには出ない。ファイルは書き換えない。**

## 材料
- 書いた行: `{{DIR}}/out/<組>.json`（rows）。今の行（直す前）: `{{DIR}}/rows_before.json`
- 材料: `{{DIR}}/materials.json`（`wp`＝Wikipedia、`o1`〜`o4`＝公式サイトの頁）。機械が `e03_check.py` で、引用が材料に在ること・数字の根拠・写しすぎ・禁止語は見終えている。**機械に見えない誤りを探す**

## 見るもの（機械に見えないもの）
1. **別の対象の話が混ざっていないか。** 公式サイトが複数の施設・境内の建物・別の館をまとめていることが多い（神社の境内社・博物館と隣の資料館・複数の島）。この行の対象（名前・分類・県）に当たる話だけか
2. **意味が変わっていないか。** 言い換えで、主語・時期・数・範囲（「一部」「かつて」「〜とされる」）が変わっていないか。材料は「伝わる」なのに断定していないか
3. **時期の古い事実を今のことのように書いていないか。** 材料の日付（年現在・開館年・改修）を確かめる。閉鎖・休止・工事・再整備・災害を書き漏らしていないか（材料の終わりの節を必ず読む）
4. **公式サイトの宣伝・行事・お知らせを事実として書いていないか。** 期間限定の催し・キャンペーンは書かない
5. **評価・主観・誇張**（機械の語リストにない言い方も）。「〜ならではの」「ぜひ」「魅力的」「見応え」など
6. **今の説明にあった事実を、材料で裏が取れないのに残していないか**（出典の無い事実は書かない）
7. **highlights**: 説明と食い違わないか・材料にある見どころか。summary を書き直していれば同じく
8. **数・年・称号**: 2か所の決め（公式サイトの頁か、Wikipedia と公式サイトの両方）を満たすか。引用が別の数を指していないか

## 出すもの（`{{DIR}}/review/R<組>.json`）
```json
{"findings": [{"slug": "…", "severity": "error|fix", "field": "description|highlights|summary", "problem": "具体的に（材料の何と食い違うか・材料の場所）", "suggest": "直し案（記事に無い事実を足さない。外すだけで済むなら外す）"}], "checked": ["slug", …]}
```
- `error`: 事実の誤り・別の対象の話・古い事実を今のことのように書いている・材料に無い事実 → 直すか外すまで出せない
- `fix`: 言い方・限定の落ち・主観の語・重複
- **材料に書いてあることを誤りと言わない。** 指摘の前に、材料の本文に該当の語があるかを必ず検索する

報告: error と fix の件数、目立った傾向を短く。
