# 2枚目以降の作例の写真を目で確かめる

`{{DIR}}/VISUAL.md` の決まり（外す種類・残す・代表写真の選び方）はそのまま使う。まずそれを全部読む。
返答・報告はすべて日本語。ネットには出ない。

## 材料
- 渡されたファイル `visual/pending<N>.json` … spotId → `{slug, name, currentCover, coverNote, files:[今回見る写真], alreadyKept:[前に見て残した写真]}`
  - `currentCover` は前に選んだ代表写真の `i`（null なら代表なし）。`coverNote` はそのときの注記
  - `files` の `path` を Read で1枚ずつ見る（3,000 バイト未満のファイルは無いはず。あれば見ずに `pending` に入れる）
- スポットの中身: `{{DIR}}/out/<組>.json` の rows（slug で引く）

## 決めること
- `files` の1枚ずつ: 残すか、外すか（理由つき）
- 代表写真: 今回の写真の中に `currentCover` より明らかに良い1枚（その場所と一目で分かる・横長・人が主役でない）があれば、その `i` に替える。
  `currentCover` が null なら、今回の写真から選ぶ。替えないなら `"cover": "keep"`。今の代表がやはり不適なら理由つきで `"cover": null`
- 1枚見たら、その場で判断を書き留める

## 出すもの
`visual/P<N>.json` に（10 か所ごとに書き出す）:
```json
{"<spotId>": {"slug":"…","exclude":[{"i":3,"reason":"…"}],"keep":[2,4],"cover":"keep","note":"（任意）"}}
```
報告: 見た枚数・外した枚数（理由の内訳）・代表を替えた／新しく付けたスポット・付けられなかったスポット。

## 第4束で分かったこと（必ず守る）
- **開いて見た写真だけ決める。** 画像が返らない（request limit・`[media removed]`）ときは、ファイル名や説明から推して決めない。
  少し間を置いて開き直し、それでも見られなければ `pending`（2枚目以降）か `"unviewed": true`（1枚目）にする。81 枚を渡した担当が
  途中から見ずに決め、全部やり直しになった
- 外す型（多かった順）: 空からの写真（ドローン・飛行機の窓・宇宙ステーション）、建物・看板・料金表・石碑・案内板が主役、
  古い絵・浮世絵・奉納額、別の山・別の場所（ファイル名が別の山の名前）、展示物・商品、人物が主役、ほとんど何も写っていない、工事中
- そのスポットで撮った写真か確かめられない（ファイル名に地名が無く景色から決められない）ものは外す方に倒す
- 代表写真は「そのスポットだと一目で分かる」もの。山の名前の山頂の祠・標柱だけ、城跡の草の斜面だけは代表にしない
