# 説明を厚くする担当（濃くする束）への指示

journey.photo の公開済みの観光スポットの説明を、**複数の出典から、こちらの言葉で組み直した独自の文章**に書き直す。
目的は、読む人にとっての中身の厚みと、検索エンジンに「似たページの量産」と見られないこと。返答・報告はすべて日本語。**ネットには出ない**（材料は手元のファイルだけ）。

## 材料
- `{{DIR}}/materials.json` … `{slug: {"wikipedia": {title,url,text}, "official": [{url,title,text}…], "skipped": […]}}`
  - 出典の記号: `wp`＝Wikipedia、`o1`〜`o4`＝`official` の1〜4番目（公式サイトの頁）
- 今の行（直す前）: `{{DIR}}/rows_before.json` … `{slug: {name, summary, description, highlights, region, category}}`
- 担当分の slug: `{{DIR}}/assign_<組>.json`

## 書くもの（`{{DIR}}/out/<組>.json`）
```json
{"rows": [{"slug": "…", "description": "…", "highlights": ["…","…","…"],
           "claims": [{"claim": "文に書いた事実を1つ", "evidence": [{"src": "wp", "quote": "材料にそのまま在る20〜60字"}, {"src": "o2", "quote": "…"}]}]}],
 "skipped": [{"slug": "…", "reason": "材料が少なく320字に届かない など具体的に"}]}
```
- `description`: **320〜620字**・一続きの文章（改行・箇条書き・「■」なし）。構成は 何がどこにあるか → 歴史・由来 → 見どころ・特徴 → 周辺や関連（材料にあれば）
- `highlights`: 3〜6個・各8〜30字。材料にある見どころの事実だけ
- `summary`（任意）: 今のものが事実と合わない・短すぎるときだけ書き直す（60〜120字）。そのままでよければ書かない
- `claims`: 説明に書いた**事実ごとに1つ**（数・年・指定・規模・名称・由来・設備）。`evidence` の `quote` は **材料のその出典の本文にそのまま在る**文字列（20〜60字・一字一句。機械が材料と突き合わせる）

## 決まり（機械が検査する）
1. **事実は材料にあることだけ。** 推測・伝承の断定・「おそらく」を書かない。伝承は「〜と伝わります」と書き、材料に在るものだけ
2. **文を写さない。** 材料の文と**連続21字以上同じ**にしない（固有名詞・指定名は別の言い方ができないので短く）。言い換え・組み替え・要約する
3. **数・年・称号の事実は2か所で確かめる。** 数字・年・「国宝」「日本一」「世界遺産」など称号を含む事実は、**公式サイトの頁に書かれているもの**か、**Wikipedia と公式サイトの両方**に在るものだけ。Wikipedia だけにある数字・年は書かない（外す）
4. **主観・誇張・評価の言い方を使わない**: 雰囲気・静か・静寂・人気・賑わ・混み・混雑・おすすめ・必見・絶景・素晴らしい・見事・圧巻・壮観・壮大・癒・魅了・感動。「落ち着いた」「多くの人が訪れる」も同じ
5. **本文に英字を入れない**（固有名詞も日本語で。無理なら外す）。禁止語: 撮りどき・撮影地・この場所・ガイド・捨て・「**」
6. **アクセス・料金・開館時間・休館日・予約の方法は書かない**（別の欄で扱う）。公式サイトの宣伝文句・キャンペーン・行事の告知も使わない
7. **時期で変わる事実**（拝観・開館・休館・工事・規制・料金・「現在」「年現在」）を書いたら、説明の末尾に「※最新の情報は公式サイトでご確認ください。」（公式サイトが無ければ「自治体や観光協会の案内で」）
8. 今の説明の事実は、材料で裏が取れるなら生かす。**取れないものは外す**（出典の無い事実は書かない）
9. 材料が薄くて320字に届かない行は、無理に伸ばさず `skipped` に理由を書く。**水増し（同じことの言い換え・一般論）をしない**

## 検査と報告
- 書いたら `SPOT_BATCH_DIR={{DIR}} python3 {{PG}}/scripts/spot-batch/e03_check.py out/<組>.json` を流し、問題を0にする（引用が材料に無い・数字の根拠・写しすぎ・禁止語・長さを見る）
- 報告: 書いた件数・見送り件数と理由・迷ったところ
